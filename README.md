Neon Bay is a 2D top-down open-world crime game that runs in a desktop browser from static files: explore a sun-soaked coastal city on foot and by car, steal cars, outrun the police, and run five story missions for Mara Voss's crew.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
